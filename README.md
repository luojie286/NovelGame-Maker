# GalGame Maker

GalGame Maker 是面向不熟悉编程的独立开发者的视觉小说制作器。目标是让创作者开箱即用，通过可视化操作制作 Galgame，并让有编程能力的创作者能够进一步定制成品游戏界面。

## 产品方向

| 能力 | 创作者要完成的工作 |
| --- | --- |
| 素材管理 | 集中管理立绘、背景等素材，按项目需求分类和查找。 |
| 文本与设定管理 | 管理剧本、对白、人物和世界观等资料，并按需扩展内容分类。 |
| 音频分类管理 | 按用途整理背景音乐、音效和语音等音频，方便制作时调用。 |
| 游戏数据库快速索引 | 从项目内容中快速定位素材、文本、设定和音频等条目。 |
| 节点化制作 | 用节点和连线组织剧情流程和选项分支。 |
| 内置版本管理 | 在制作器内管理游戏项目的版本。具体记录和恢复方式待定。 |
| AI 辅助 | 批量处理重复、规则明确的简单工作。优先支持哪些任务待定。 |
| 游戏界面自定义 | 允许创作者通过可视化操作调整成品游戏界面，并为程序员提供进一步自定义的入口。 |

## 待确认的决策

- 第一版要支持的最小制作流程及其验收终点。
- 制作器的运行平台、游戏运行时和导出目标。
- 项目存储与索引方案、内置版本管理方式。
- AI 批处理的优先任务与接入方式。
- 无代码界面编辑的范围，以及代码扩展的边界和接口。
