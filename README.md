# GalGame Maker

GalGame Maker 是面向不熟悉编程的独立开发者的视觉小说制作器。目标是让创作者开箱即用，通过可视化操作制作 Galgame，并让有编程能力的创作者能够进一步定制成品游戏界面。

功能范围见[产品需求](docs/requirements.md)。模块边界和扩展方式见[技术架构](docs/architecture.md)。开工前的字段、分支与存档规则见[首版数据契约](docs/data-contracts.md)，测试和规模目标见[首版架构验收](docs/architecture-verification.md)。

## 产品方向

| 能力 | 创作者要完成的工作 |
| --- | --- |
| 素材管理 | 集中管理立绘、背景等素材，按项目需求分类和查找。 |
| 文本与设定管理 | 管理剧本、对白、角色和世界观等资料。角色记录姓名、介绍及关系图，可选一张整体设定立绘作为识别图。游戏画面所用的角色立绘单独管理，按神态、服装、动作分类供剧情引用。内容分类可按需扩展。 |
| 音频分类管理 | 按用途整理背景音乐、音效和语音等音频，方便制作时调用。 |
| 游戏数据库快速索引 | 通过本地可重建的 SQLite FTS5 派生索引，按数据版本增量同步，毫秒级检索并定位素材、正文、设定、角色、节点和摘录。 |
| 节点化制作 | 一个可命名的节点按播放顺序容纳对白和演出。开发者可创建全局与节点局部的 `int`、`bool` 变量，在节点连接上配置进入目标节点时的变量变化。单一后继可自动衔接；多个后继可用 `and`、`or`、`not`、`is`、`is not` 和括号组合判断。制作器通过后台增量 Z3 检查检验子节点条件不能同时成立，非叶节点无可进入的后继时报告错误警告。不同路线可以汇合到同一个节点，也可复制节点用于独立编辑。节点连接不允许形成回环。术语见 [CONTEXT.md](CONTEXT.md)。 |
| 结局与片尾 | 叶节点可设置为播完后结束。创作者可直接导入并播放现成的片尾 MP4，也可提供制作人名单和片尾曲，选择预设或自定义风格，由软件生成独立的片尾报幕 MP4。生成的视频可在制作器中预览，并随游戏导出供引擎播放。 |
| 内置版本管理 | 在制作器保存/加载边界内置 `.versions/` 版本存储，支持自动与命名快照、按稳定对象 ID 对比差异、基于内容哈希去重保留/清理历史素材，以及恢复前的格式与完整性校验。 |
| AI 辅助 | 批量处理重复、规则明确的简单工作。优先支持哪些任务待定。 |
| 游戏界面自定义 | 允许创作者通过可视化操作调整成品游戏界面，并为程序员提供进一步自定义的入口。 |

## 第一版验收目标

制作器首版支持 Windows。创作者的制作项目保存为文件夹，导入的素材复制到该文件夹，整个项目可以移动并继续编辑。首版优先打通项目创建、内容导入、剧情编辑、预览和导出的完整流程，支持剧情中的背景音乐与音效、替换对话框、选项按钮和菜单的图片与基础样式，也支持导入并播放现成的片尾 MP4。制作、预览、导出和游戏游玩均可离线完成，只有 AI 辅助需要联网。导出的游戏支持存档与读档。

创作者可以导出一个游戏目录，其中包含 Windows `.exe` 和作品资源文件。玩家保留导出的目录结构，双击 `.exe` 即可游玩，无需安装 GalGame Maker。

项目包含 Galgame 游戏引擎，负责读取导出作品的剧情和资源，运行节点、对白与选项分支，并呈现游戏界面和音频。

首版使用 Python 3.13、PySide6 和 PyInstaller。制作器与播放器共用 Python 剧情引擎。具体方案见 [首版技术选型](docs/requirements.md#首版技术选型)。

## 开发现状

首版 MVP 核心能力及 P2 进阶能力已完成实现，仓库包含纯 Python 剧情引擎、版本化项目读写与素材复制/替换/完整性校验、内置项目版本管理（历史快照、按稳定对象 ID 对比差异、内容哈希去重保留/清理历史素材、恢复前完整性与格式校验）、可重建的本地 SQLite FTS5 派生快速索引（按数据版本增量更新，支持中文毫秒级检索与定位）、会话级增量后台 Z3 分支检查、深色创作器界面（ComfyUI 风格可平移缩放节点图与快捷拖线连接、独立实时画面预览窗口、节点局部变量与分支选项独立管理、文件夹式缩略图素材浏览器与音视频试听条、可拖拽人物关系图、文本与活摘录管理、界面主题实时预览、版本管理面板、调试预览）、视觉小说叠加式独立播放器（3 个手动存档槽位、点击/键盘推进、按容量分页）、原子目录导出和原创合成短篇。示例项目位于 `examples/short_story/`，媒体来源记录在其 `asset-sources.json`。协作约定与命令见 [AGENTS.md](AGENTS.md)。后续将围绕完整产品需求继续推进离线打包真机回归及扩展能力建设。

## 开发运行

在 Windows x64 上使用 Python 3.13。

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-maker.txt
.\.venv\Scripts\python.exe -m galgame_maker.maker
.\.venv\Scripts\python.exe -m unittest discover -s tests
pwsh -File tools/build_maker.ps1
```

制作器目录包位于 `dist/GalGameMaker/`，其中预置独立播放器。制作器导出的游戏目录包含 `GalGamePlayer.exe`、`game.json` 和用到的 `assets/`。合成示例资源可用 `.\.venv\Scripts\python.exe -m tools.create_example` 生成，该命令要求目标示例目录尚不存在，并需要构建机上的 FFmpeg。
